# <序号>-<标题>开发文档

## 数据结构

> 每个数据结构写成一个条目，条目之间用 `---` 分隔。条目格式如下，「结构」按类型二选一：
>
> - **代码结构**（类、结构体等）：用类 py 伪代码描述，并为每个字段（元素）写注释；
> - **表格结构**（数据库表等）：用表格描述，表头即其每个字段。

---

名称：<名称>
类型：<类 / 结构体 等代码结构>
说明：<这个数据结构是什么、用来做什么>
结构：

```python
class <类型名>:
    <字段名>: <类型>  # <字段说明>
    <字段名>: <类型>  # <字段说明>
```

---

名称：<名称>
类型：<数据库表 / 表格结构>
说明：<这个数据结构是什么、用来做什么>
结构：

| <字段1> | <字段2> | <字段3> |
| --- | --- | --- |
| 类型 | 类型 | 类型 |
| 说明 | 说明 | 说明 |
