## 数据结构

> 每个数据结构写成一个条目，条目之间用一行由 `=` 组成的横线分隔（独占一行，前后各留一个空行）。条目内每个字段独占一行，不得将多个字段写在同一行。条目格式如下，「结构」按类型二选一：
>
> - **代码结构**（类、结构体等）：用类 py 伪代码描述，并为每个字段（元素）写注释；
> - **表格结构**（数据库表等）：用表格描述，表头即其每个字段。
