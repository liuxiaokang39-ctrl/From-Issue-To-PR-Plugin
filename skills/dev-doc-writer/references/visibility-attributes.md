# 函数公开属性定义

公开属性按可见范围分三档；**未显式声明时一律按私有函数处理**。

## 公有接口

- **定义**：暴露给外部 / 其他模块的调用入口，如前端调用、第三方调用者使用。
- **可见范围**：模块外的任意调用者。
- **设计要求**：需长期稳定、考虑向后兼容；变更时先评估影响面。

## 公有函数

- **定义**：包内可见，但不对最外层暴露。例如后端公有函数对全后端可见，但前端不可见。
- **可见范围**：同一包 / 同一侧（如后端）内部。

## 私有函数

- **定义**：包内私有，仅在自身模块内可见。
- **可见范围**：仅定义它的模块内部。
- **默认档位**：未显式声明即归入此档。
