# 资源生命周期规则

设计数据结构（类、结构体等）时，必须明确每个字段对资源的所有权，以及对象销毁时的释放责任。

## 所有权分类

| 字段类型 | 含义 | 对象销毁时的处理 |
| --- | --- | --- |
| 独占拥有 | 当前对象是该资源的唯一所有者 | 必须释放该资源 |
| 借用 | 只临时使用资源，不拥有其生命周期 | 只断开引用，不释放资源 |
| 共享 | 与其他对象共同持有，资源由共享机制管理 | 只断开引用，不释放资源 |

## 销毁顺序

对象销毁时，按「从内到外、从成员到容器」的顺序释放其独占拥有的资源：

1. 先释放成员内部持有的资源；
2. 再释放成员自身；
3. 最后释放容器持有的资源与容器本身。

非拥有字段（借用 / 共享）只断开引用，不得释放其生命周期。

## 设计要求

- 在数据结构字段注释中标注所有权：独占拥有 / 借用 / 共享；
- 为独占拥有资源的数据结构明确销毁行为（析构函数、关闭 / 释放方法或等价机制）；
- 不得为借用 / 共享字段设计释放动作，避免重复释放或释放他人资源。
