# 资源生命周期规则

编写涉及对象创建与销毁、资源获取与释放的代码时，遵循以下规则。

## 释放责任

- 对象销毁时，必须释放其**独占拥有**的全部资源（如内存、文件、连接、句柄、锁）；
- 仅借用或共享引用的数据，只断开引用（置空、解除绑定等），不得释放其生命周期；
- 不得释放不属于当前对象的资源。

## 释放顺序

按「从内到外、从成员到容器」释放：

1. 先释放成员内部持有的资源；
2. 再释放成员自身；
3. 最后释放容器持有的资源与容器本身。

## 实现要求

- 语言提供析构 / Drop / Dispose / Close 等机制时，在其中完成释放；没有时，在对象生命周期结束时显式调用释放方法；
- 释放后不得再次释放同一资源；借用 / 共享引用只清除引用，不调用释放；
- 不得因为「可能没人再用」而释放非拥有资源。
