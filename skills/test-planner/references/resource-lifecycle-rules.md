# 资源生命周期测试规则

设计测试场景时，必须验证对象销毁时的资源释放行为。

## 必测场景

- **独占拥有**：对象销毁后，其拥有的资源已被释放；
- **借用 / 共享**：持有者销毁后，资源仍然存活，仅引用被断开；
- **释放顺序**：按「从内到外、从成员到容器」释放；
- **重复销毁**：不得发生重复释放或释放他人资源。

## 设计要求

- 用可观察释放的测试替身（计数器、spy、fake 资源）验证，不依赖垃圾回收时机；
- 只为真实存在的所有权与释放行为设计场景；无需释放的普通值字段不新增场景；
- 优先通过公开行为验证；无法从外部观察时，按开发文档中的销毁契约设计；
- 期望结果必须可判定，不得写「资源被正确释放」这类模糊表述。
