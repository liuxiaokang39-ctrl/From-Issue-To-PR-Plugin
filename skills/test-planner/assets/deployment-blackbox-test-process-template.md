## 1. 测试目标

验证 `<系统 / 服务>` 在真实部署形态下的端到端行为：

- 真实启动部署，使用真实的网络、数据库、外部服务与配置；
- 按真实用户操作路径验证需求文档中的每项期望行为与期望结果；
- 只依据外部可观察的输入与输出判断结果，不依赖内部函数或私有状态。

## 2. 验收标准

- 需求文档中的每项需求均有对应的端到端场景；
- 「测试步骤与期望结果」中的每个场景均在真实部署环境中实际执行，实际结果与期望结果一致；
- 不存在未执行、跳过、使用 mock 替代真实依赖或静默吞错的场景；
- 人类审核确认的补充场景已全部纳入。
