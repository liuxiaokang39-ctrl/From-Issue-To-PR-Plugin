# 集成白盒测试流程样板

> 样板草稿：生成实际文档时替换 `<...>` 占位符，删除本说明。本文档只记录测试设计，不写入测试执行结果。

## 1. 测试目标

验证 `<工作区 / 模块>` 在真实调用链与流程图状态流转下的集成行为：

- 以函数间调用链、流程图状态迁移为粒度，覆盖模块协作、数据传递与状态变化；
- 集成白盒场景须覆盖工作区的全部代码；
- 对其中每个公有接口追加集成黑盒场景，只依据公开契约判断结果，不依赖内部实现。

## 2. 验收标准

- 「工作区范围」列出的每个文件与函数均被至少一个集成场景覆盖；
- 流程图中的每条状态流转均有对应场景，且实际结果与期望结果一致；
- 每个公有接口均有集成黑盒场景且全部通过；
- 不存在未执行、跳过或静默吞错的场景。
