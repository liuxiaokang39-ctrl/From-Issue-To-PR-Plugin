# 函数文档模板（Rustdoc Markdown）

> 固定格式。只允许按事实填写：参数含义、错误码、返回值语义、示例行为必须能在 rustdoc JSON 或 AST 结果中找到依据。
> 无法证实的内容用 `<!-- 未确认：... -->` 标记，并登记到「未确认字段清单」；定稿前必须确认后删除占位标记。

## 适用范围

- 本模板只用于源码 `///` 注释，且只用于公有接口（公有函数、公有 trait 方法）。
- 私有函数、数据结构（结构体、枚举、联合体、类型别名等）不写源码注释：私有函数记录在
  `docs/data-struct-and-interface/<模块名>/private-functions.md`，数据结构记录在 `data-structures.md`；公有函数另汇总在 `public-functions.md`。格式见 `assets/module_interface_doc.md`。

## 固定格式

````rust
/// 一句话说明函数职责。
///
/// # Arguments
/// * `name` - 参数含义与取值约束。
///
/// # Returns
/// 返回值语义。
///
/// # Errors
/// 返回错误的场景与对应错误类型 / 错误码。
///
/// # Examples
/// ```
/// use mycrate::foo;
///
/// let value = foo("x")?;
/// assert_eq!(value, 1);
/// # Ok::<(), mycrate::Error>(())
/// ```
pub fn foo(name: &str) -> Result<u32, mycrate::Error> { ... }
````

## 章节规则

| 章节 | 何时必须出现 | 事实来源 |
| --- | --- | --- |
| 摘要 | 总是 | rustdoc JSON 的 doc 摘要；缺失时只能由人类确认 |
| `# Arguments` | 存在非 `self` 参数 | 参数名与类型取自 rustdoc JSON；含义只能取自既有 doc 或人类确认 |
| `# Returns` | 返回值非 `()` | 返回值类型取自 rustdoc JSON；语义只能取自既有 doc 或人类确认 |
| `# Errors` | 返回 `Result` | 触发条件只能取自 doc 注释、AST 错误分支位置或人类确认 |
| `# Examples` | 每个公有函数建议提供 | 必须与真实签名一致，且能通过 `cargo test --doc` |

## 书写规则

- 使用中文书写，代码标识符用反引号包裹。
- 参数顺序与签名严格一致，不得增删参数。
- 不得新增固定格式之外的一级章节（如 `# Panics`、`# Safety`）；panic 风险登记到未确认字段清单，由人类决定如何表述。
- 不得写未经证实的错误码、错误枚举名或返回值取值。
- 示例必须使用真实类型与函数签名；无法编译验证的示例不得写成已验证。
- 签名与 `rustdoc JSON` 不一致时停止写作，先重新生成 JSON，不在文档里「适配」签名。

## 未确认标注

- 临时占位：在待确认的具体位置写 `<!-- 未确认：需要确认的内容 -->`，禁止整段用泛泛的「待补充」敷衍。
- 每条未确认项必须同时进入「未确认字段清单」，字段为：函数、字段、原因、需人类确认的内容、位置（`文件:行号`）。
- 校验脚本会把源码 doc 中残留的「未确认」视为失败，因此占位标记不能进入最终代码。
