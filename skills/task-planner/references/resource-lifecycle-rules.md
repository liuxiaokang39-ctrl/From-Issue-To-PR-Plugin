# 资源生命周期任务规则

拆分任务时，必须把对象销毁时的资源释放纳入任务范围。

## 适用范围

- 类 / 结构体独占拥有资源（如内存、文件、连接、句柄、锁）时，必须有任务覆盖其销毁时的释放行为；
- 仅借用或共享引用的字段，不产生释放任务；销毁时只断开引用。

## 拆分要求

- 释放任务须写明释放顺序：从内到外、从成员到容器；
- 同一资源的释放只能归属一个任务，禁止拆到多个任务，避免重复释放；
- 释放任务的验收标准必须可观察（如资源已关闭、已释放、引用已断开），不得写「正常销毁」这类不可判定表述；
- 开发文档未定义所有权或销毁行为时，回到 `dev-doc-writer` 补齐，不自行脑补。

## 不做什么

- 不为借用 / 共享字段新增释放任务；
- 不为无需显式释放资源的普通值字段新增任务。
