# 002 实现订单创建校验

- 任务：实现订单创建校验
- 工作区：order（读写）——src/order/validation.py
- 产出：validate_order 函数
- 验收标准：
  - 用户 id 为空时返回 INVALID_USER
  - 金额小于等于 0 时返回 INVALID_AMOUNT
  - 上述校验均通过时返回 None

## 实现内容

### 函数定义

---

函数名称：validate_order
公开属性：私有函数
多线程属性：普通
函数归属：独立函数
所属模块或包：order.validation
职责说明：校验待创建的订单数据，不合法时返回对应错误。
入参列表：

| 名称 | 类型 | 是否必填 | 含义 |
| --- | --- | --- | --- |
| order | Order | 是 | 待创建的订单数据 |

返回值列表：

| 名称 | 类型 | 含义 |
| --- | --- | --- |
| error | OrderError | 合法时为 None，否则为对应错误 |

错误返回：

| 错误类型 | 错误码 | 错误场景 |
| --- | --- | --- |
| OrderError | INVALID_USER | 用户 id 为空 |
| OrderError | INVALID_AMOUNT | 金额小于等于 0 |

校验规则：黑盒校验
调用关系：

| 方向 | 函数 |
| --- | --- |
| 调用（内部函数） | — |
| 被调用（调用方） | create_order |

函数内部流程图：

```mermaid
flowchart TD
    A[开始] --> B{user_id 是否为空}
    B -- 是 --> C[返回 INVALID_USER]
    B -- 否 --> D{amount 是否大于 0}
    D -- 否 --> E[返回 INVALID_AMOUNT]
    D -- 是 --> F[返回 None]
    C --> G[结束]
    E --> G
    F --> G
```
